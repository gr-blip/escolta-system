# Using Superpowers Skill

**Purpose:** Introduction to the Superpowers development workflow.

## What is Superpowers?

Superpowers is a complete development methodology that makes you a more effective developer through:

1. **Brainstorming** - Refine ideas through questions
2. **Git Worktrees** - Isolated workspaces
3. **Writing Plans** - Detailed implementation plans
4. **Subagent-Driven Development** - Parallel execution
5. **Test-Driven Development** - RED-GREEN-REFACTOR
6. **Requesting Code Review** - Structured review process
7. **Finishing Branches** - Proper completion workflow

## Superpowers Principles

### 1. Think Before Code

```markdown
- Brainstorm ideas
- Ask questions
- Understand requirements
- Plan approach
```

### 2. Isolate Work

```markdown
- Use git worktrees
- Clean workspaces
- No stashing needed
- Easy context switching
```

### 3. Plan Before Implement

```markdown
- Create detailed plans
- Document context
- Define success criteria
- Break into steps
```

### 4. Test First

```markdown
- Write tests first
- RED-GREEN-REFACTOR
- No code without tests
- Verify behavior
```

### 5. Review Before Merge

```markdown
- Self-review first
- Request code review
- Address feedback
- Verify quality
```
